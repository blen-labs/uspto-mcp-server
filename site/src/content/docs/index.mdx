## How it works

<Steps>

1. **Find the call.** `search_api` searches the SDK documentation for the methods that fit the
   question.
2. **Read its shape.** `describe_schema` returns a method's signature and a ready-to-run example.
3. **Run a program.** Your assistant writes a short JavaScript program, and `execute` runs it in
   a sandbox with no network, file, or environment access.

</Steps>

Your keys stay in the server process and never enter the sandbox. The server sends one request at
a time for each key, as USPTO requires.
