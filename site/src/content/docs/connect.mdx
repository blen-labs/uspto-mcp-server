## ChatGPT and other remote clients

ChatGPT, Claude custom connectors, and Gemini Enterprise connect to a remote server over HTTPS. They
do not start a server on your computer. To use them, run the server's HTTP transport on a host that
you control: see [Self-host](/self-host/).

## Check that it works

Ask your assistant:

> Has anyone challenged patent 10,169,987 at the PTAB?

The assistant calls `search_api` to find the right methods, then `execute` to run them.

| Message | Cause | Fix |
| --- | --- | --- |
| `SourceUnavailable` | The key for that source is missing or blank. | Add the key to your client's configuration. See [Get your keys](/keys/). |
| `Unauthorized` | USPTO refused the ODP key. | Check the key, and see [Keep a key working](/keys/#keep-a-key-working). |
| `NotFound` on every trademark call | TSDR reports a key that it refuses as not found. | Check the TSDR key. |
| `SandboxUnavailable` | No sandbox runtime is available for `execute`. | Install [Deno](https://docs.deno.com/runtime/getting_started/installation/). |

<Aside>
  The built-in sandbox needs no install on Node.js 24 and 26 on macOS (Apple silicon), Linux (x64
  and arm64), and Windows (x64). On other systems the server uses Deno.
</Aside>
