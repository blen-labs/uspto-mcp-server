## Tips

- **Filter first.** USPTO serves one request at a time for each key, so calls queue. One
  well-filtered search is better than many lookups.
- **Pass `fields` on every search.** Full patent and PTAB records are large.
- **Start with a small `limit`**, 5 to 25. `count` gives the total.
- **Use `facets`** to get counts without a page through the records.
- **Return less.** A returned value over 256 KiB fails with `ResultTooLarge`.
- **No matches is not an error.** A search with no matches returns `{ count: 0, …Bag: [] }`.

The [SDK reference](/reference/sdk/) lists every method.
